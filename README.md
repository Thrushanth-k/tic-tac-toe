# 🎮 Tic Tac Toe

A simple, fun, and mobile-friendly **Tic Tac Toe game** built using HTML, CSS, and JavaScript.

The game is designed with a clean student-friendly theme and can be played directly from a web browser without installing anything.

## 🌐 Live Demo

**Play the game:**
https://thrushanth-k.github.io/tic-tac-toe/

## ✨ Features

* 🎮 Two-player gameplay
* ⚫ Black `X`
* 🔴 Red `O`
* 🏆 Automatic winner detection
* 🔵 Winning line when three symbols match
* 🤝 Draw detection
* 🔄 Restart game button
* 📱 Mobile-friendly responsive design
* 💻 Works on desktop and mobile browsers
* 🌳 Simple wooden background
* 🚀 Hosted for free using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Game structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Game logic and winner detection
* **GitHub Pages** – Free web hosting

## 🎯 How to Play

1. Player X starts the game.
2. Player X and Player O take turns.
3. Place three of your symbols in:

   * A horizontal row
   * A vertical column
   * A diagonal
4. The first player to get three matching symbols wins.
5. If all boxes are filled without a winner, the game ends in a draw.
6. Click **Restart Game** to play again.
